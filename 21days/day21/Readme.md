# 💰 Smart Expense Tracker

A command-line based Python application to manage daily expenses, track spending, and generate reports in CSV and PDF format.

---

## 🚀 Features
- Add and manage expenses
- Categorize spending
- View total expenses
- Set monthly budget
- Save data in CSV format
- Export professional PDF reports

---

## 🛠️ Technologies Used
- Python
- CSV Module
- ReportLab (PDF generation)
- Datetime
