# 💰 Smart Expense Tracker (CLI-Based)

A powerful command-line based Python application that helps users track daily expenses, manage budgets, and generate professional reports in CSV and PDF formats.

---

## 📌 Overview

Managing personal finances is an essential skill. This project provides a simple yet effective solution to record, analyze, and monitor expenses using Python. It demonstrates real-world implementation of Object-Oriented Programming (OOP), file handling, and report generation.

---

## 🚀 Key Features

### 🧾 Expense Management
- Add daily expenses with:
  - Amount
  - Category (Food, Travel, Shopping, etc.)
  - Description
  - Automatic date tracking

### 📊 Financial Tracking
- View all recorded expenses
- Calculate total spending
- Track monthly budget
- Get remaining balance after expenses

### 💾 Data Storage
- Stores all expense data in **CSV format**
- Easily accessible in Excel or Google Sheets
- Persistent data storage (data remains after program restart)

### 📄 Report Generation
- Export expense reports as **PDF**
- Clean tabular format
- Suitable for submission or sharing
